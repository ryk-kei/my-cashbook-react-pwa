# 私用の出納簿アプリ

## 目的

- 自作の出納簿アプリをAndroidで使用したい
- iOSの出納簿アプリからデータ移行したい
- テキストファイル形式でバックアップとりたい

## 使い方

ブラウザからアクセスしてインストールする(PWA)

## 仕様

- PWA (やむなくpublic)
- IndexedDB
- CSVインポート (既存データに対して追加登録)
- JSONインポート (idに対して上書き登録)

## 入出力定義

### 1. CSV (ダブルクォーテーションなし)

|    日付    |  項目  | 金額 |  収支  |
| :--------: | :----: | :--: | :----: |
| yyyy-mm-dd | 文字列 | 数値 | 論理値 |

### 2. JSON

|    日付    |  項目  |  金額  |   収支   |  id  |
| :--------: | :----: | :----: | :------: | :--: |
|    date    |  item  | amount | isIncome |  id  |
| yyyy-mm-dd | 文字列 |  数値  |  論理値  | 数値 |
